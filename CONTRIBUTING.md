# Contributing

1. Read `CLAUDE.md`: the product principles and content rules apply to every change.
2. Keep PRs small: one roadmap item or one fix.
3. Run `npm test` before opening a PR.
4. Health content:
   - cite a public source (AAP/HealthyChildren.org, NHS, CDC, WHO or a national health service)
   - paraphrase, don't copy
   - list new or changed cards in the PR description under **Needs clinical review**
5. Be kind in issues and reviews. Many contributors are new or expecting parents.
